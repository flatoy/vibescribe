Redesign review
VibeScribe · redesign review

Hold a key, speak, and it’s pasted.

The overlay and language picker stay much as they are. The settings window is rebuilt as a first-launch setup plus a sidebar settings window. Every page in the switcher above shows exactly the same screens and states; only the brand changes.

Kept

  • Overlay position, shape and dark glass
  • Language picker search, look and ⌥⇧ shortcut
  • Language code next to the menu bar icon
  • Hold or tap Right ⌥
  • Clipboard restore after pasting

Removed

  • Logs tab as top-level navigation. Moved into About & diagnostics.
  • Large title and tagline at the top of the window
  • “Request” buttons on permissions that are already granted
  • 100-item language dropdown, which duplicated the picker
  • “Change this in code” hotkey note
  • 100 px “Latest transcript” box. Replaced by History.

Added

  • Guided first launch where the download runs while you grant permissions
  • Input Monitoring status (required, but not shown today)
  • Shortcut recorder and hold/tap mode
  • Pinned and recent languages with ⌘1–⌘3
  • Vocabulary hint for names and jargon
  • History with search, copy and paste again
  • Microphone choice and input level meter
  • Overlay outcomes: pasted, copied, nothing heard, errors, esc to cancel
  • Richer menu bar menu with the last transcript
Replaces the “Setup” tab

First launch

Setup is a short sequence in its own window. The 630 MB download starts on the first screen and runs in the footer while you grant permissions, so most people never wait on a progress bar. The steps are numbered because order matters: permissions before the practice run.

Kept, with more states

Overlay

Same place and shape. The red dot becomes the live spectrum waveform, driven by the mic level, so you can see it’s hearing you. The overlay now shows how each recording ended, then fades after about 1.2 s. It stays click-through.

Kept, with shortcuts

Language picker

This is now the only place to choose a language. Settings opens it instead of its own dropdown. Pinned languages sit at the top with ⌘1–⌘3, and native names help when you search by the name you know.

Today: “Settings” and “Quit”

Menu bar

The menu bar is where VibeScribe spends most of its time, so it shows status. The icon reflects what the app is doing, and the menu covers most daily tasks: copy the last transcript, switch language, or open history.

Replaces Home + Logs tabs

Settings window

A sidebar in the style of System Settings, with each page covering one topic. Permissions aren’t listed when everything is fine; problems appear as a banner and a dot on the sidebar item. A status card at the bottom of the sidebar replaces the old header.

Settings → Speech model

Speech model states

Today the model is invisible once it’s ready. This page shows what’s installed, how much space it uses, and offers an optional faster model for people who prefer speed over accuracy in rare languages. Downloads use the same filling waveform as setup.

For when we build it

Build notes

How each addition maps onto the current code, roughly from smallest to largest effort. None of it needs a new dependency.

Overlay outcomesAdd pasted / copied / noSpeech / cancelled / error cases after finalizing in RecordingSession. The pill widens to fit, and the window width must follow the content, not a fixed 180 pt.
Live waveformRMS from the buffers AudioCaptureController already delivers, smoothed to about 20 Hz and published to OverlayView.
Input Monitoring rowCGPreflightListenEventAccess() and CGRequestListenEventAccess() in Permissions. Poll on app activation so rows update without a button.
Pinned and recent languagesTwo arrays in Preferences. The picker gets sections, and the fuzzy matcher returns match ranges for highlighting.
Shortcut recorderPersist a Hotkey in Preferences and feed it to HotkeyListener. Record through the same event tap.
VocabularyWhisperKit DecodingOptions.promptTokens: tokenise the word list once when it changes.
Open at loginSMAppService.mainApp.register(), which needs the packaged .app and does nothing under swift run.
HistoryA small JSON or SQLite store in Application Support, with the frontmost app name captured at paste time. Retention is pruned on launch.
Microphone choiceEnumerate with AVCaptureDevice.DiscoverySession, then set the input device on the audio engine. This one is the most fiddly.
Turbo modelThe optional one. The manifest and verification already exist, so this means parameterising WhisperModelSetup by model ID.
